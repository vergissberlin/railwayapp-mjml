# AGENTS.md

## Purpose
This file defines template-specific agent conventions for this Railway app.

## Scope
These rules apply to `railwayapp-mjml`.
The workspace root `AGENTS.md` also applies.

## Conventions
- Use Conventional Commits in English (for example: `feat:`, `fix:`, `docs:`, `chore:`).

## README Banner Rule

- Keep the README header format aligned with other `railwayapp-*` template repositories:
  - title line
  - `![Template Header](./template-header.svg)` directly below the title
  - short description text
- Keep the shared footer marker and badge section in README:
  - `<!-- footer -->`
  - `---`
  - template badge list
